# Legacy Oracle Cloud deployment

These files were written for the abandoned Oracle Cloud Always Free virtual
machine plan (systemd, nginx, DuckDNS, local uploads). They are kept only for
reference and are **not** used by the current deployment:

- Frontend: Vercel Hobby
- Backend: Render Free
- Database: Supabase Free PostgreSQL
- File storage: Backblaze B2

See `deployment/README.md` for the current configuration. The migration tooling
does not depend on anything in this directory.
